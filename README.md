# usage-alert

A Claude Code plugin that shows your current plan usage in the status line and alerts you (toast + desktop notification) each time a usage window passes another 10%.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install usage-alert --marketplace shaharyavital/usage-alert
```

From a shell:

```bash
claude plugin install usage-alert --marketplace shaharyavital/usage-alert
```

Answer `y` to add the marketplace, then pick a scope.
